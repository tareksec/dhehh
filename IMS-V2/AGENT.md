# IMS v2 — Agent Rules

> IMS v2-তে কাজ করা যেকোনো AI এজেন্টের (Claude Code, Codex …) জন্য বাধ্যতামূলক নিয়ম।
> রিপোর সাধারণ নিয়ম `CLAUDE.md` ও `AGENTS.md` আগে; এই ফাইল তার উপরে IMS v2-এর বাড়তি নিয়ম। দুটোর মধ্যে বিরোধ হলে থেমে মালিককে জিজ্ঞেস করো।

---

## ১. এখনকার অবস্থা

- **কোড শুরু হয়েছে (মালিক, 2026-10-19: "all implement now")।** ফেজ ১–৬ বানানো হয়েছে, ব্রাঞ্চ `feature/ims-v2`। ফেজ ৭-এর ডেটা আনা বাদ (Q10, মালিক: পুরনো IMS আর নেই); বাকি শুধু ডোমেন চালু করা।
- কোডে কী কোথায়: `PROJECT_GUIDE.md` → Investor / Mudarabah Module → IMS v2; কী বদলেছে: `CHANGELOG.md` [Unreleased]; বানানোর সময় নেওয়া সিদ্ধান্ত: `PLAN.md` ভাগ ৭।
- "পরের ফেজ শুরু করব?" ধরনের প্রস্তাব বারবার দেবে না। মালিক নিজে বলবেন।

## ২. কাজ শুরুর আগে এই ক্রমে পড়ো

1. `CLAUDE.md`, `AGENTS.md` — রিপোর নিয়ম।
2. `IMS-V2/README.md` — সূচি।
3. `IMS-V2/PLAN.md` — ফ্লো ও মালিকের সিদ্ধান্ত (ভাগ ৬)। **সিদ্ধান্ত হয়ে যাওয়া প্রশ্ন আবার জিজ্ঞেস করবে না।**
4. কাজ অনুযায়ী: `PRD.md` (কী), `TRD.md` (কীভাবে), `ARCHITECTURE.md` (কোথায়), `DESIGN.md` (দেখতে কেমন), `ROLES.md` (কে কী পারে)।
5. পুরনো IMS-এর নিয়ম দরকার হলে `docs/IMS-MAJOR-SYSTEMS-VERIFIED.md`।

## ৩. মালিকের ঠিক করা নিয়ম (বদলাবে না)

| বিষয় | নিয়ম |
|---|---|
| কোথায় | ERP-র ভেতরে, একই অ্যাপ ও ডেটাবেস (অপশন A)। আলাদা অ্যাপ/ডেটাবেস নয়। |
| ডোমেন | মালিকের কেনা আলাদা **মূল ডোমেন**, সাবডোমেন নয়। কোডে কোনো ডোমেন লেখা নয়; অ্যাডমিন সেটিংসে বসানো। মূল ঠিকানায় পোর্টাল, `/office`-এ অফিস। সার্ভার সেটআপ (Cloudflare, Coolify) মালিক নিজে করেন — এজেন্টের VPS অ্যাক্সেস নেই। |
| লাভ | প্রজেক্টে অ্যাডমিনের বসানো ইনভেস্টর %; কোনো ফিক্সড ডিফল্ট নয়। ইনভেস্টরদের মধ্যে **শুধু টাকার অনুপাতে**। |
| ক্ষতি | একই % ইনভেস্টরদের ভাগে, মূলধন থেকে কাটা; কেউ বিনিয়োগের বেশি হারাবে না; গ্রুপেও। "কোম্পানি পুরো ক্ষতি বহন" অপশন থাকবে। |
| বাদ | ডকের "টাকা × মাস" ওজন, পুলের cap/min। |
| লাভের উৎস | কেনাকাটা লিংক করে অটো হিসাব + হাতে লেখা, দুটোই। |
| মূলধন ফেরত | মেয়াদ ঐচ্ছিক; মেয়াদে ফেরত, না থাকলে ৬০ দিনের নোটিশ। |
| পোর্টাল | একটাই — এখনকার পোর্টাল IMS v2 হবে। |
| খবর | পোর্টাল নোটিফিকেশন + SMS + ইমেইল। |
| KYC | নতুনদের বাধ্যতামূলক। |
| লুক | `DESIGN.md` ও `design-references/`; বাংলা + ইংরেজি; পুরো মোবাইল; নন-টেকনিক্যাল মালিকের জন্য খুব সহজ। |

## ৪. করবে

- প্রতিটা নতুন সিদ্ধান্ত `PLAN.md` ভাগ ৬-এ লিখে রাখো (তারিখ ও "মালিক")। চ্যাটে রেখে দিও না।
- এক ফাইলে কিছু বদলালে অন্য ফাইলে একই কথা থাকলে সেখানেও মেলাও (PRD ↔ TRD ↔ ARCHITECTURE ↔ DESIGN ↔ ROLES)।
- কোডের কোনো দাবি লেখার আগে কোড খুলে যাচাই করো; ফাইল/লাইনের নাম দাও।
- টাকার প্রতিটা নিয়ম উদাহরণসহ লেখো (যেমন "% = ৩৫, ক্ষতি ১,০০,০০০ → ইনভেস্টর −৩৫,০০০")।
- মালিকের সঙ্গে বাংলায়, সহজ ভাষায় কথা বলো; প্রশ্ন শুধু যেটা সত্যিই না জানলে এগোনো যায় না।

## ৫. কখনো করবে না

- মালিকের অনুমোদন ছাড়া কোনো ব্যবসার নিয়ম বানানো বা বদলানো (`CLAUDE.md`)।
- আগে সেটেল হওয়া প্রজেক্ট বা পরিশোধিত payout আবার হিসাব করা।
- পোর্টালে কাস্টমার, সাপ্লায়ার, ইনভয়েস, ইউনিট দাম, মার্জিন বা অন্য ইনভেস্টরের তথ্য দেখানো।
- ERP-র কেনাকাটা, স্টক, বিক্রি নতুন করে বানানো।
- `main`-এ push বা merge মালিকের অনুমতি ছাড়া; force-push; secret বা `.env` কমিট।
- ডেমো/ডেভ ডেটাবেসে `migrate:fresh`, seeder, `--env` দিয়ে টেস্ট।
- রেফারেন্স ছবির ব্র্যান্ড, নাম, লোগো বা মানুষের ছবি কপি।

## ৬. কোড শুরু হলে (তখনকার জন্য)

- ব্রাঞ্চ: `feature/ims-v2` (একই বিষয়ের সব কাজ এখানে)।
- ক্রম: `PLAN.md` ভাগ ৫ — এক ফেজ শেষ করে পরেরটা।
- কোড কোথায়: `ARCHITECTURE.md` §৫ (`app/Ims/`, `app/Filament/Ims/Office|Portal/`, `resources/css/filament/ims/` …)।
- প্রতিটা কাজে: `CHANGELOG.md` + `UPDATE_NOTES.md`, `PROJECT_GUIDE.md` আপডেট; প্রতিটা লেখা `lang/en.json` + `lang/bn.json`; নতুন মডেল `BelongsToCompany` + `MultiCompanyIsolationTest`; `ModuleGuard`; MySQL 8.4-এ ইনডেক্সের নাম।
- **UI নিয়ম:** `AGENTS.md` বলে ড্যাশবোর্ড/অ্যাডমিন UI শুধু Filament-এর ডিফল্ট কম্পোনেন্টে। তাই IMS-এর লুক আসবে Filament থিম (CSS টোকেন, `DESIGN.md` §৩) আর Filament কম্পোনেন্ট দিয়ে — এখনকার ইনভেস্টর পোর্টালের থিম যেভাবে। কোনো স্ক্রিনে নিজস্ব কম্পোনেন্ট লাগলে আগে মালিকের অনুমতি নাও।
- টাকার কোডে টেস্ট বাধ্যতামূলক (`TRD.md` §১০); টেস্ট শুধু `php artisan test`।
- শেষ করার আগে: আক্রান্ত টেস্ট + পুরো `php artisan test`, CSS বদলালে `npm run build`; ৩৬০px ও ডেস্কটপে, বাংলা ও ইংরেজিতে স্ক্রিন দেখে নাও।
- শেষ হলে `feature/ims-v2`-এ কমিট ও push (রিপোর নিয়ম); `main` নয়।
