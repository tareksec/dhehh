# IMS v2

ইনভেস্টর ও বিনিয়োগের সব কাজ এক জায়গায় — এই ERP-র ভেতরে, নিজের লুকে, নিজের আলাদা মূল ডোমেনে। পুরনো IMS (`tareksec/ims`) এটা দিয়ে বদলানো হবে।

**অবস্থা (2026-10-19): ফেজ ১–৬ বানানো হয়েছে** (ব্রাঞ্চ `feature/ims-v2`)। চালু হবে যখন সুপার অ্যাডমিন ERP-তে IMS ডোমেন বসিয়ে IMS চালু করবেন। ফেজ ৭ (পুরনো IMS-এর ডেটা) বাকি। বানানোর সময়ের সিদ্ধান্ত: `PLAN.md` ভাগ ৭।

## এক নজরে

- **লাভ-ক্ষতি:** প্রজেক্টে অ্যাডমিনের বসানো %; ইনভেস্টরদের মধ্যে টাকার অনুপাতে; ক্ষতি মূলধন থেকে কাটা, কখনো বিনিয়োগের বেশি নয়।
- **ডোমেন:** আলাদা মূল ডোমেন; মূল ঠিকানায় ইনভেস্টর পোর্টাল, `/office`-এ স্টাফ।
- **নতুন যা আসবে:** KYC, OTP রেজিস্ট্রেশন, প্রজেক্টের স্বচ্ছতা, অটো লাভ প্রস্তাব, হিসাব ফ্রিজ, মেয়াদ ও মূলধন ফেরত, ফিড, সাপোর্ট থ্রেড, SMS + ইমেইল + পোর্টাল নোটিফিকেশন, মাসিক স্টেটমেন্ট, স্টেটমেন্ট মেলানো।
- **লুক:** সবুজ ফিনটেক ড্যাশবোর্ড; বাংলা + ইংরেজি; ফোনে আগে; নন-টেকনিক্যাল মালিকের জন্য খুব সহজ।
