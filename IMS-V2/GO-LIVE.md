# IMS v2 — চালু করার চেকলিস্ট

> **এই ফাইল কী:** IMS v2 (ইনভেস্টর পোর্টাল + IMS অফিস) আসল সার্ভারে চালু করার ধাপ, ক্রম অনুযায়ী। প্রতিটা ধাপ শেষ হলে `[ ]` এর জায়গায় `[x]` দিন।
> **কে করবে:** "আপনি" = মালিক (সার্ভার, ডোমেন, সিদ্ধান্ত)। "সুপার অ্যাডমিন" = ERP-তে Super Admin রোলের কেউ।
> **লেখা:** 2026-10-19 (IMS-V2/PLAN.md ফেজ ৭)। পুরনো IMS-এর ডেটা আনা লাগবে না (Q10); পুরনো sync API বন্ধ করা হয়ে গেছে।

---

## ধাপ ১ — কোড নিরাপদ করা ও `main`-এ আনা

- [ ] **কোড push করা।** এখন সব কাজ শুধু একটা কম্পিউটারে (`feature/ims-v2`, কমিট হয়নি)। Claude-কে "push" বললে ব্রাঞ্চে কমিট করে GitHub-এ পাঠাবে।
- [ ] **ব্রাঞ্চের চেক সবুজ।** GitHub-এ টেস্ট ও MySQL 8.4 মাইগ্রেশন চেক (`.github/workflows/mysql-migrations.yml`) পাস করেছে কিনা দেখা।
- [ ] **ডেটাবেসের ব্যাকআপ।** `main`-এ আনার আগে আসল ডেটাবেসের ব্যাকআপ নেওয়া (IMS v2-এ অনেক নতুন টেবিল ও কলাম আসছে)।
- [ ] **`main`-এ আনা — শুধু আপনার অনুমতিতে।** Coolify `main` পেলেই নিজে ডিপ্লয় করে।

## ধাপ ২ — ডিপ্লয়ের পর সার্ভারে যাচাই

- [ ] **মাইগ্রেশন চলেছে।** Coolify-র Post-deployment Command (`php artisan deploy:migrate`) নিজে চালায়; ডিপ্লয় লগে এরর নেই কিনা দেখা।
- [ ] **OCR প্যাকেজ বসেছে।** Coolify-তে একবার **Redeploy** (নতুন বিল্ড) দিলে `tesseract-ocr` ও `tesseract-ocr-ben` বসে। কন্টেইনারের Terminal-এ `tesseract --list-langs` চালালে `ben` আর `eng` দেখাবে। না বসলেও চলবে — তখন KYC চোখে দেখে যাচাই হয় (`docs/deployment.md` → "IMS v2: KYC OCR")।
- [ ] **শিডিউলার চলছে।** প্রতি মিনিটে `php artisan schedule:run` চলা লাগে (অন্য কাজের জন্য আগে থেকেই চলার কথা)। IMS-এর রোজকার কাজ এর ওপর নির্ভর করে: লাভের প্রস্তাব (৭:০০), মেয়াদের রিমাইন্ডার (৮:০০), অফিসের সকালের করণীয় (৮:০৫), মাসিক স্টেটমেন্ট (১ তারিখ ৯:০০), শিপমেন্ট দেরির খবর (প্রতি ঘণ্টা)।

## ধাপ ৩ — ডোমেন (আপনি নিজে, বা VPS-এর AI এজেন্ট)

> VPS-এর কাজ AI এজেন্টকে দিয়ে করালে তাকে পুরো `IMS-V2/VPS-AGENT-BRIEF.md` ফাইলটা দিন — ধাপ ১-এর ব্যাকআপ, ধাপ ২-এর যাচাই আর এই ধাপ সেখানে এজেন্টের জন্য লেখা আছে।

- [ ] **ডোমেন কেনা।** আলাদা মূল ডোমেন, সাবডোমেন নয় (যেমন `example.com`)।
- [ ] **Cloudflare:** দুটো A রেকর্ড — `@` আর `www` — VPS-এর IP-তে। প্রক্সি চালু (কমলা মেঘ), SSL মোড **Full (strict)**।
- [ ] **Coolify:** ERP অ্যাপের **Domains**-এ `https://example.com` আর `https://www.example.com` দুটোই যোগ করে সেভ ও Redeploy। SSL নিজে হয় (Let's Encrypt)।
- [ ] **যাচাই:** ব্রাউজারে `https://example.com` খুললে কিছু একটা (ERP বা এরর পেজ) তালা-চিহ্নসহ আসছে। IMS এখনো বন্ধ, তাই ইনভেস্টর পেজ আসবে না — এটাই ঠিক।

## ধাপ ৪ — চালুর আগে সেটিংস (সুপার অ্যাডমিন)

- [ ] **SMS গেটওয়ে:** Settings → Integrations → SMS Gateway পূরণ। লগইন কোড, পাসওয়ার্ড রিসেট আর খবরের SMS এটা দিয়েই যায়।
- [ ] **ইমেইল (SMTP):** Site → Storefront Settings → (মূল সাইটের সারি) → Customer Notifications & Reminders → SMTP host, port, username, password, from address। এটা ছাড়া ইমেইলে পাসওয়ার্ড রিসেট, মাসিক স্টেটমেন্ট আর অফিসের সকালের ইমেইল যাবে না (পোর্টালের ভেতরের নোটিফিকেশন তবুও যাবে)।
- [ ] **SMS-এর লেখা:** Settings → SMS Templates → "IMS news" অংশে নিজের ভাষায় লেখা।
- [ ] **চুক্তি:** IMS অফিস → Tools → Agreement Templates-এ চুক্তিপত্র publish করা (ইনভেস্টর পোর্টালে accept করবে)।
- [ ] **রোল:** কে কী করবে দেখে নেওয়া (`IMS-V2/ROLES.md`) — Manager সেটেল, KYC, টাকা নিশ্চিত করতে পারে; Accountant payout ব্যাচ, মূলধন ফেরত, স্টেটমেন্ট মেলাতে পারে। দরকারে Settings → Roles-এ বদলানো।
- [ ] **প্রজেক্ট/গ্রুপের ইনভেস্টর %:** প্রতিটা চলমান প্রজেক্ট ও গ্রুপে ইনভেস্টরের ভাগ % ঠিক আছে কিনা দেখা — লাভ আর ক্ষতি দুটোতেই এই % খাটে (Q1)।

## ধাপ ৫ — IMS চালু করা (সুপার অ্যাডমিন)

- [ ] ERP-তে **Investments → Investor Portal Settings → IMS v2 on its own domain**: ডোমেন লিখুন (`example.com`, `www` ছাড়া), **IMS v2 switched on** চালু, সেভ।
- [ ] **যা সঙ্গে সঙ্গে বদলায়:** `https://example.com` খুললে ইনভেস্টর পোর্টাল; `https://example.com/office` খুললে IMS অফিস (স্টাফের নিজের ERP লগইন দিয়ে)। পুরনো ইনভেস্টর পোর্টালের ঠিকানা নতুন ডোমেনে চলে যায়। ERP-র Investments মেনু অফিসের লিংক হয়ে যায়। নতুন ইনভেস্টরের টাকা KYC যাচাই ছাড়া চালু হয় না (পুরনোদের চলমান টাকা আগের মতোই চলে)।
- [ ] **IMS অফিস → Tools → IMS settings:** কোন খবর SMS-এ, কোনটা ইমেইলে যাবে; "ইনভাইট দিয়ে যোগদান" চালু কিনা; মেয়াদের কত দিন আগে রিমাইন্ডার; রোজকার কাজগুলো (প্রস্তাব, রিমাইন্ডার, সকালের তালিকা, মাসিক স্টেটমেন্ট, শিপমেন্ট দেরি) চালু/বন্ধ।
- [ ] **বন্ধ করতে হলে:** একই জায়গায় সুইচ বন্ধ করলেই আগের অবস্থা — ডেটা কিছু মোছে না।

## ধাপ ৬ — প্রথম দিনের যাচাই (একজন পরীক্ষার ইনভেস্টর দিয়ে)

- [ ] অফিস থেকে নিজের বা পরিচিত একজনকে **ইনভাইট** → ফোনে কোড → তথ্য, নমিনি, পাসওয়ার্ড → পোর্টালে ঢোকা যায়।
- [ ] পোর্টালে **KYC** (NID দুই পাশ + সেলফি) জমা → অফিসের **KYC**-তে অনুমোদন।
- [ ] খোলা গ্রুপে টাকা জমা → **Money to confirm**-এ নিশ্চিত → পোর্টালে টাকা দেখাচ্ছে, নোটিফিকেশন এসেছে।
- [ ] **পাসওয়ার্ড ভুলে গেছি** — SMS-এ আর ইমেইলে দুইভাবেই কোড আসে।
- [ ] ফোনে (ছোট স্ক্রিনে) আর কম্পিউটারে, বাংলা আর ইংরেজিতে পোর্টাল ও অফিস খুলে দেখা।
- [ ] পরের দিন সকালে অফিসের করণীয় ইমেইল এসেছে কিনা (SMTP থাকলে)।

## ধাপ ৭ — চালুর পরে পরিষ্কার

- [ ] **পুরনো sync কী মুছে ফেলা:** Settings → Integrations → Website API-তে "Data sync (old IMS, turned off)" বা "Investor sync (old IMS, turned off)" লেখা কোনো কী থাকলে **Revoke**। API আগেই বন্ধ, তাই এগুলো কিছু খুলতে পারে না — শুধু তালিকা পরিষ্কার রাখা।
- [ ] **পুরনো IMS অ্যাপ:** একই VPS-এ আলাদা অ্যাপ হিসেবে `zamzaminv.app` চলছিল (PLAN.md ভাগ ৪)। আর দরকার না থাকলে Coolify থেকে বন্ধ করা; ওই ডোমেনই IMS v2-এর ডোমেন হলে আগে ওই অ্যাপ থেকে ডোমেন সরিয়ে ERP-তে যোগ করা।
- [ ] **বাংলা লেখা একবার পড়ে দেখা:** `UPDATE_NOTES.md`-এ "Needs Bangla review" তালিকা।

## জানা সীমা (ঠিক আছে, শুধু জেনে রাখা)

- একই পণ্য দুই প্রজেক্টের কেনায় থাকলে সেই বিক্রি অটো হিসাবে ধরা হয় না; অফিস লাভ হাতে লেখে (মালিক নিশ্চিত করেছেন)।
- PDF-এ জটিল যুক্তাক্ষর মাঝে মাঝে পুরো জোড়া লাগে না (PDF লাইব্রেরির সীমা)।
- চ্যানেল পার্টনারের রেকর্ডে ইমেইল নেই, তাই তাদের পাসওয়ার্ড রিসেট শুধু SMS-এ।
- অফিসের সুপার অ্যাডমিনদের জন্য ২-ধাপ লগইন (2FA) এখনো নেই — চাইলে পরে যোগ করা যায় (PLAN.md ভাগ ৪ক)।
