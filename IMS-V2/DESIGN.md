## ১. তিনটা বাধ্যতামূলক শর্ত (মালিক)

1. **খুব সহজ।** মালিক নন-টেকনিক্যাল — প্রতিটা স্ক্রিন এক নজরে বোঝা যাবে।
2. **পুরোপুরি মোবাইল রেসপন্সিভ।** ফোনে আগে।
3. **বাংলা + ইংরেজি।** পুরো সফটওয়্যার, এক ক্লিকে বদল।

## ২. সহজ রাখার নিয়ম

| নিয়ম | উদাহরণ |
|---|---|
| সহজ শব্দ, জারগন নয় | "Settlement confirmed" নয় → "লাভ হিসাব হয়ে গেছে"; "Payout pending" → "টাকা পাঠানো বাকি" |
| প্রতি স্ক্রিনে একটা প্রধান কাজ | একটা বড় সবুজ বাটন; বাকিগুলো হালকা |
| বড় সংখ্যা, ছোট লেবেল | "৳ ৫,২০,০০০" বড়; নিচে ছোট ধূসরে "আমার মোট বিনিয়োগ" |
| অবস্থা রং + লেখা | সবুজ বিন্দু + "পরিশোধিত"; শুধু রং নয় |
| খালি অবস্থায় পরের কাজ লেখা | "এখনো কোনো বিনিয়োগ নেই — খোলা গ্রুপ দেখুন" + বাটন |
| ভুলের বার্তা সমাধানসহ | "পরিমাণ বাকির চেয়ে বেশি — সর্বোচ্চ ৳ ৯,৬৫,০০০" |
| বিপজ্জনক কাজে নিশ্চিতকরণ | Void, পরিশোধ, অনুমোদন — কী হবে তা লিখে "হ্যাঁ, করুন" |
| সংখ্যার পাশে মানে | "+১২.৮%" এর পাশে "গত মাসের চেয়ে" |
| মালিকের হোমে "আজ কী করতে হবে" সবার আগে | করণীয় তালিকা, প্রতিটায় এক ট্যাপে কাজের জায়গা |
| ↗ বাটন = বিস্তারিত | প্রতিটা কার্ডের কোণে, রেফারেন্সের মতো |

## ৪. লেখা (Typography)

- ফন্ট: **Hind Siliguri** (বাংলা ও ইংরেজি দুটোই; ERP-তে আগে থেকেই নিজস্ব হোস্টেড)। ইংরেজির জন্য আলাদা জিওমেট্রিক ফন্ট লাগলে বানানোর সময় নমুনা দেখিয়ে ঠিক।
- মাপ: পেজ-শিরোনাম ২৮–৩২px; KPI সংখ্যা ২৮–৩৬px (ভারী); কার্ড-শিরোনাম ১৬px; লেবেল ১৩px ধূসর; শরীর ১৫–১৬px।
- টাকা: "৳ ৩২,৬৭৮" বড়, ".৯০" হালকা রঙে (রেফারেন্সের মতো)।
- বাংলা লেখা ইংরেজির চেয়ে ~৩০% লম্বা — কার্ডে জায়গা রাখা, কখনো কেটে না যায়।

## ৫. সংখ্যা ও তারিখ

- বাংলায় বাংলা অঙ্ক ও লাখ-গ্রুপিং (৳ ৫,২০,০০০); ইংরেজিতে ইংরেজি অঙ্ক, লাখ-গ্রুপিং রাখা (৳ 5,20,000) — বাংলাদেশের অভ্যাস।
- তারিখ: "১৫ জুন ২০২৬" / "15 Jun 2026"।
- লাভ সবুজ "+", ক্ষতি লাল "−", সঙ্গে লেখা।

## ৬. লেআউট

### ৬.১ ডেস্কটপ (রেফারেন্স ১)

- উপরে গোল সাদা হেডার: বাঁয়ে লোগো, মাঝে পিল-মেনু, ডানে সার্চ, ঘণ্টা, প্রোফাইল ছবি, ভাষা বদল।
- বাঁয়ে সরু আইকন-সাইডবার, গ্রুপ করা গোল পিলে, সক্রিয়টা সবুজ গোল; প্রতিটা আইকনে লেখা টুলটিপ।
- "স্বাগতম, নাম" বড় শিরোনাম; ডানে তারিখ-পরিসর ও প্রধান কাজের বাটন।
- কার্ডের গ্রিড: ১২ কলাম, ফাঁক ২০–২৪px।

### ৬.২ মোবাইল (রেফারেন্স ২)

- নিচে ৫ ট্যাবের বার (আইকন + লেখা)।
- উপরে শুভেচ্ছা + ছবি + ঘণ্টা।
- গাঢ় সবুজ বড় কার্ড প্রথমে, তারপর গোল দ্রুত-কাজের বাটন, তারপর তালিকা।
- টেবিল → কার্ড-তালিকা; ফর্ম এক কলাম; প্রধান বাটন নিচে স্টিকি।
- ট্যাপের জায়গা ≥ ৪৪px; ৩৬০px চওড়ায় কিছু কাটে না, পাশে স্ক্রল নেই।
- ব্রেকপয়েন্ট: ৩৬০ / ৭৬৮ / ১০২৪ / ১২৮০।

## ৮. স্ক্রিন

### ৮.১ পোর্টাল (ইনভেস্টর) — ফোন আগে

| স্ক্রিন | মূল জিনিস |
|---|---|
| স্বাগত / লগইন | বড় শিরোনাম, ছবি, এক বড় সবুজ বাটন; "অ্যাকাউন্ট আছে? লগইন" |
| ইনভাইট / OTP / পাসওয়ার্ড | এক স্ক্রিনে এক ধাপ, উপরে ধাপের দাগ (১/৩) |
| হোম | শুভেচ্ছা → মোট বিনিয়োগ কার্ড → দ্রুত-কাজ → মোট লাভ ও পরের payout → প্রজেক্টের অগ্রগতি → সাম্প্রতিক লেনদেন; KYC বাকি থাকলে উপরে ব্যানার |
| বিনিয়োগ | গ্রুপ/প্রজেক্ট কার্ড, অগ্রগতি, মেয়াদ, ফেরতযোগ্য মূলধন |
| প্রজেক্ট | আপডেট, মাইলস্টোন, শিপমেন্ট, মোট সংখ্যা ("আনুমানিক" চিহ্ন), রিপোর্ট |
| লাভ ও Payout | মাসওয়ারি বার চার্ট, payout তালিকা, স্ক্রিনশট, রসিদ, নেবে/রিইনভেস্ট বাছাই |
| ফিড | পোস্ট কার্ড, ছবি, লাইক, কমেন্ট |
| স্টেটমেন্ট | মাস বাছাই, তালিকা, PDF ডাউনলোড |
| অনুরোধ ও সাপোর্ট | টপ-আপ, টাকা তোলা, প্রশ্নের থ্রেড |
| নোটিফিকেশন | তালিকা, সব পড়া |
| প্রোফাইল | মেনু-তালিকা: তথ্য, KYC, নমিনি, ব্যাংক, চুক্তি, ডকুমেন্ট, ভাষা, পাসওয়ার্ড, লগআউট |
| পার্টনার | আমার ইনভেস্টর, কমিশন, ইনভাইট লিংক শেয়ার |

নিচের ট্যাব: **হোম · বিনিয়োগ · লাভ · ফিড · প্রোফাইল**।

### ৮.২ অফিস (স্টাফ) — ডেস্কটপ আগে, ফোনেও চলে

| স্ক্রিন | মূল জিনিস |
|---|---|
| হোম (মালিক) | "আজ কী করতে হবে" (সবচেয়ে জরুরি ৩টা + "সব দেখুন"), ৪টা বড় সংখ্যা, চলমান গ্রুপ, এই মাস বনাম গত মাস |
| ইনভেস্টর | তালিকা (খোঁজ, ফিল্টার), প্রোফাইল, বিনিয়োগ, KYC, ব্যাংক, পোর্টাল খোলা |
| KYC রিভিউ | ছবি পাশাপাশি, OCR-এর ফল, চেকলিস্ট (সবুজ টিক/লাল ক্রস), অনুমোদন/প্রত্যাখ্যান |

## ৯. দুই ভাষা

- প্রতিটা লেখা `__()`-এ, `lang/en.json` ও `lang/bn.json`-এ একসঙ্গে।
- ভাষা বদল সব জায়গা থেকে (হেডার, প্রোফাইল, লগইন পেজ); ইনভেস্টরের পছন্দ মনে থাকে; ইমেইল/SMS/PDF সেই ভাষায়।
- অ্যাডমিনের লেখা কন্টেন্ট (প্রজেক্টের নাম, আপডেট, ফিড পোস্ট) যেমন লেখা তেমন দেখায়।
- বাংলা অনুবাদ নিশ্চিত না হলে ইংরেজি রেখে `UPDATE_NOTES.md`-এ "Needs Bangla review"।
